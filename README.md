# Criba — Explorador de números primos

Explorador visual de enteros con **criba de Eratóstenes animada**, números clicables y desglose de factores para compuestos.

## Abrir

- Repositorio: https://github.com/andyariana01-ship-it/explorador-primos
- Vista previa: https://htmlpreview.github.io/?https://github.com/andyariana01-ship-it/explorador-primos/blob/main/index.html
- Espejo: https://raw.githack.com/andyariana01-ship-it/explorador-primos/main/index.html

Abre `index.html` en el navegador (no hace falta compilar).

## Qué incluye

- Cuadrícula de 1..n (20–220) con estados: candidato, primo, compuesto, primo actual.
- Reproducir / pausa / paso / saltar / reiniciar y cuatro velocidades.
- Narración de cada paso de la criba.
- Clic en un entero: si es primo se explica; si es compuesto, factorización y árbol.
- Lista de primos encontrados y contador π(n).
- Atajos: espacio, flecha derecha, R.
